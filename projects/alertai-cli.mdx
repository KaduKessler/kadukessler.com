  ## Context

  The team's daily routine meant juggling multiple terminals and repeating setup steps across AlertAI's codebase. I built a single command-line tool to replace that.

  ## What I built

  - A dotnet global tool that consolidates day-to-day developer commands (build, run, dev, release, status) into one place

  - Hardened after the first release based on real day-to-day usage
