contentEn: |
  ## Context

  Started as an internal tool for a DayZ game clan, then generalized so any server could reuse it without fixed branding. Players browse a catalog, reserve items, and an admin tracks each order through to completion.

  ## What I built

  - Catalog with search, filters (type, status, tags), and price sorting, with an image carousel and zoom per item
  - Order flow: reserve an item, track status under "My Orders", cancel while still pending
  - Ammunition damage table, sortable, with a logarithmic magnitude bar since damage values range from tens to billions

  ![Ammunition damage table with logarithmic magnitude scale](/images/projects/bazarz-tabela-dano.png)

  - Discord login (NextAuth) with automatic user sync to Directus, plus a Discord webhook notifying on every new order
  - Restricted admin panel for stock management, gated by user role

  ## Stack

  Next.js 15 (App Router), React 19, TypeScript, and Tailwind CSS 4 on the frontend; Directus as a headless CMS/backend running in Docker; NextAuth for Discord OAuth.

  ## Focus

  Keep the marketplace flow simple for players while giving admins full visibility over stock and orders, without hardcoding it to one specific clan or server.

  ## Contexto

  - Login via Discord (NextAuth) com sincronização automática de usuário no Directus, mais um webhook do Discord notificando a cada novo pedido
  - Painel administrativo restrito pra gestão de estoque, controlado por cargo de usuário

  ## Stack

  Next.js 15 (App Router), React 19, TypeScript e Tailwind CSS 4 no frontend; Directus como CMS/backend headless rodando em Docker; NextAuth pro OAuth do Discord.

  ## Foco

  Manter o fluxo do marketplace simples pro jogador enquanto dá ao admin visibilidade completa sobre estoque e pedidos, sem prender o projeto a um clã ou servidor específico.
