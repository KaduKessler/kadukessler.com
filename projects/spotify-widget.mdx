contentEn: |
  ## Context

  GitHub profile READMEs commonly embed a "now playing" Spotify widget, but most rely on someone else's hosted service and a shared API key. I wanted a self-hosted version anyone could run for themselves, with proper multi-user support instead of a single-owner script.

  ## What I built

  - **Backend**: Fastify API serving the public `/widget` SVG route and the admin panel's REST API, with SQLite + Prisma for storage
  - **Admin SPA**: React + Vite panel to configure appearance (theme, background, scale, effects), manage users/roles, and generate the embed URL
  - **Auth & RBAC**: password or GitHub OAuth login, with admin/user/viewer roles; each user stores their own Spotify credentials, no shared global API key
  - **Deploy**: single `docker compose up` container, auto-generates an admin password on first run

  ![Live widget embed, showing whatever I'm currently playing on Spotify](https://spotify.kadukessler.com/widget?user=KaduKessler)

  ## Focus

  Zero-config self-hosting and per-user isolation. Every instance owner controls their own Spotify link and appearance without touching a shared config.
contentPt: |
  ## Contexto

  READMEs de perfil do GitHub costumam ter um widget "tocando agora" do Spotify, mas a maioria depende do serviço hospedado de outra pessoa e de uma API key compartilhada. Eu queria uma versão self-hosted que qualquer um pudesse rodar por conta própria, com suporte real a múltiplos usuários em vez de um script de dono único.

  ## O que construí

  - **Backend**: API em Fastify servindo a rota pública `/widget` (o SVG) e a API REST do painel administrativo, com SQLite + Prisma pro armazenamento
  - **Admin SPA**: painel em React + Vite pra configurar aparência (tema, fundo, escala, efeitos), gerenciar usuários/papéis e gerar a URL de embed
  - **Auth & RBAC**: login por senha ou GitHub OAuth, com papéis admin/user/viewer; cada usuário guarda suas próprias credenciais do Spotify, sem API key global compartilhada
  - **Deploy**: um único container via `docker compose up`, que gera sozinho uma senha de admin na primeira execução

  ![Widget ao vivo, mostrando o que eu tô ouvindo agora no Spotify](https://spotify.kadukessler.com/widget?user=KaduKessler)

  ## Foco

  Self-hosting sem configuração e isolamento por usuário. Cada dono de instância controla seu próprio link do Spotify e a aparência do widget sem mexer numa config compartilhada.
