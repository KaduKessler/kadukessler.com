The original variable WOFF2 files are retained as fallback fonts.
The Latin WOFF2 files are subsets of those originals, generated with FontTools.
They preserve variable weights, glyph outlines, layout features and license names.

Subset Unicode ranges:
U+0000-00FF, U+0300-036F, U+2000-206F, U+20A0-20CF,
U+2190-21FF, U+FEFF, U+FFFD.

CSS selects the smaller subsets for these ranges and the original files for
other supported characters. Regenerate the subsets when updating the originals.
